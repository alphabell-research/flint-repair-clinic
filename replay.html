THE REPAIR

Reset the things
that keep running.

The leaking implementation starts a new virtual spawn timer on restart without clearing the old one. A clean score and a centered ship hide the leftover work.

The fixed implementation clears the old timer before starting a new run. Replay comparison then matches the fresh run across all saved gameplay states.

The lab tracks collisions but keeps the ten-second simulation running. The separate 30-second soak check covers finite values and bounds for its seeded input schedule. These checks describe this illustration; they do not establish complete gameplay correctness for other games.
